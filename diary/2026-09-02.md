### 💡 Key Architectural Insights & Decisions:
- **Sequential Asset Dependency Context:** Independent code generation for HTML, CSS, and JS without shared context causes subtle class mismatches and broken styling. Passing previously generated artifacts into subsequent synthesis steps ensures coherent, bug-free single-page web applications.
- **Specialized Gateway Routing:** Directing file-level coding tasks to Inference's `/v1/forge/generate-code` endpoint provides lower latency, purpose-built prompt wrappers, and higher code quality compared to general-purpose conversational endpoints.
