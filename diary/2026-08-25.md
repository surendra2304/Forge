## Bugs / Errors Discovered
### Bug #01: Duplicate Thread Start on aiosqlite Connection Await
- Symptoms: `RuntimeError: threads can only be started once` during `init_db()` in test runs.
- Root Cause: Calling `async with await aiosqlite.connect()` invoked `__await__` and `__aenter__` sequentially.
- Fix: Refactored `DatabaseManager` to expose an `asynccontextmanager` method `connection()`.
- Verification: All 14 initial async unit/integration tests passed.

### Bug #02: Task State Transition Matrix Incomplete for PENDING Tasks
- Symptoms: Attempting to pause a task in `PENDING` state threw `Cannot transition task from PENDING to BLOCKED`.
- Root Cause: Initial `TRANSITION_MATRIX` only permitted `PENDING -> READY | CANCELLED`.
- Fix: Updated `TRANSITION_MATRIX` to permit `PENDING -> BLOCKED | RUNNING | READY | CANCELLED` allowing early suspension and direct execution.
- Verification: `test_task_lifecycle_pause_resume_cancel` and `test_runs_audit_trail` passed.
