- Symptoms: `anthropic_key` was redacted as `[REDACTED_TOKEN]` via string pattern instead of `[REDACTED_SECRET]` via key name in test.
- Root Cause: `SENSITIVE_KEYS` did not include bare `"key"` substring match.
- Fix: Added `"key"` to sensitive substring list in `SecretRedactor`.
