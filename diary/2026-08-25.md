## Bugs / Errors Discovered
### Bug #01: Duplicate Thread Start on aiosqlite Connection Await
- Symptoms: `RuntimeError: threads can only be started once` during `init_db()` and `DatabaseManager.get_connection()` in test runs.
- Root Cause: Calling `async with await aiosqlite.connect()` invoked `__await__` and `__aenter__` sequentially on the same `Connection` context manager, attempting to start the background thread twice.
- Fix: Refactored `DatabaseManager` to expose an `asynccontextmanager` method `connection()` that wraps `async with aiosqlite.connect(...) as conn:` cleanly.
- Verification: All 14 async unit and integration tests passed without error.
