## User Directives / Requirements
- **Phase 5: Verification Engine (`app/verification/`)**:
  - Enforce "evidence over model confidence" philosophy.
  - Build objective verification adapters: `BuildChecker` (AST syntax compile check), `LintChecker` (static code linter), `TestChecker` (pytest test suite runner), and `RuntimeChecker` (CLI / service smoke test).
  - Capture structured `VerificationEvidence` (check category, command, exit code, stdout, stderr, execution duration, inspected artifacts).
  - Aggregate battery into `VerificationReport` and persist as workspace artifact.
- **Phase 6: Debugging & Self-Repair / Recovery (`app/recovery/`)**:
  - `FailureClassifier`: Categorize failures into `SYNTAX_ERROR`, `DEPENDENCY_MISSING`, `LOGIC_BUG`, `INTEGRATION_ERROR`, `TIMEOUT`, `PERMISSION_DENIED`, `ENVIRONMENT_ERROR`, `UNKNOWN`.
  - Perform root-cause diagnosis (extract failing file, line, error message, stack trace).
  - Minimal surgical patch synthesis and application (`PatchApplicator`).
  - `AntiLoopController`: Max retry limits per failure class (default: 3), SHA256 patch hash deduplication (prevent repeated identical patches without new evidence), and escalation boundaries.
- **Section 24 MVP: Standalone CLI (`app/cli.py`)**:
  - Support commands:
    - `forge build "<goal>"`: Triggers full autonomous engineering loop: Task Analyzer -> 8-Stage Planner -> Workspace Provisioning -> Specialist Agent Dispatch -> Execution Engine -> Verification Battery -> Self-Repair (if failed) -> Completion Report.
    - `forge status <task-id>`
    - `forge logs <task-id>`
    - `forge pause <task-id>`
    - `forge resume <task-id>`
    - `forge cancel <task-id>`
    - `forge inspect <task-id>`
  - Register `forge` console script entry point in `pyproject.toml`.

## Bugs / Errors Discovered
### Bug #04: Windows Console Unicode Encoding Error on Legacy Terminal
- Symptoms: `UnicodeEncodeError: 'charmap' codec can't encode character '\U0001f528'` when running `forge build` in PowerShell.
- Root Cause: Default stdout encoding on Windows PowerShell without UTF-8 codepage failed to render unicode emojis.
- Fix: Added `sys.stdout.reconfigure(encoding="utf-8", errors="replace")` and replaced emoji headers with ASCII text markers.
- Verification: Passed.

### Bug #05: Foreign Key Failure in Recovery Event Logging
- Symptoms: `sqlite3.IntegrityError: FOREIGN KEY constraint failed` when `RecoveryEngine` recorded audit event without existing parent task in test.
- Root Cause: Test invoked recovery before persisting task entity in `StateStore`.
- Fix: Added `store.create_task` setup in `test_recovery.py`.
- Verification: Passed.
